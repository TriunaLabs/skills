03 / ACTION PLAN

Turn evidence into fixes.

These actions follow from the fixture’s observed differences. They are suggestions, not proof of improved comprehension or indexing.

01 · HIGH

Expose the sibling route in source HTML

Put the heading and link on the starting page before JavaScript runs. The corrected page demonstrates this.

02 · REVIEW

Keep page metadata stable

The script changes the description and canonical URL after render. Choose the intended values in the initial response and confirm them across views.

03 · TEST FIXTURE

Repair the missing destination

The fictional home page includes one link to an absent file solely to exercise link checking. A real site should remove or repair it.
