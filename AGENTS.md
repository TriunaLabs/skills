# Working on this library

Keep changes inside this repository. Skills are public, original contributions; do not import personal or installed skills without explicit selection and license review. Each skill has portable SKILL.md instructions and catalog.json metadata. Compatibility means format compatibility unless backed by a recorded runtime evaluation. Do not claim an agent was tested without evidence.

Run `python scripts/validate.py`, `python -m unittest discover -s tests`, and `python scripts/build.py` before publishing. The site is static and uses relative assets for GitHub Pages project paths. Never add a CNAME without a verified domain setup request. Do not run contributed skill scripts during catalog builds.
