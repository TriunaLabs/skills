      Git is authoritative

      The range establishes commits and changed paths, not deployment or test success.

      Evidence is explicit

      Issues, tests, deployment, rollback, and limitations appear only when supplied.

      Publication is separate

      This artifact stays a draft and does not tag, deploy, announce, or publish.
