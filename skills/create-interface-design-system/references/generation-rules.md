# Generation rules

Use the local profiles as bounded starting points, not as claims that an industry has one correct aesthetic. Score the product, audience, tasks, and tone together. Supplied brand evidence wins over the profile.

Every output must cover nine domains: atmosphere, semantic color roles, functional typography, component states, spacing and grid, elevation, do/don't guardrails, responsive behavior, and an agent prompt.

Prefer a small coherent token set. Name tokens by purpose. Preserve a usable system font fallback. Generate real focus-visible states, state text, and input error treatment. Responsive rules must say what reflows, collapses, scrolls, or remains fixed.
