# Optional decision adapters

Use a decision provider only for bounded choices after deterministic constraints are applied. Candidate labels can include visual direction, density, navigation pattern, and elevation level. Send the brief and aggregate design evidence, not private assets unless the user authorizes it.

Record provider, policy identifier, candidate labels, selected label, confidence, cost when available, and fallback. Low confidence returns to deterministic scoring or human review. Provider output never overrides contrast, required component states, supplied brand constraints, or platform accessibility requirements.
