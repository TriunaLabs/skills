# Review rubric

Use the deterministic report as an observation layer. Apply editorial judgment before changing the page.

| Dimension | Strong evidence | Common failure | Action |
| --- | --- | --- | --- |
| Audience and answer | One audience, one decision, a clear H1, and a concise opening proposition | Keyword-shaped headline with no clear offer | Rewrite for the reader's decision, not exact-match phrasing |
| Information architecture | Sections follow the questions needed to decide | Generic Features/Benefits blocks repeat claims | Replace vague headings with specific outcomes or useful questions |
| Entity clarity | Product, organization, and responsible person are unambiguous where relevant | Brand, product, and author relationships are unclear | Add visible ownership and consistent identity links |
| Evidence | Material claims point to named, checkable support | Statistics, logos, and superlatives have no source | Remove, qualify, or support each claim |
| Technical access | Important copy is readable in source, indexed where intended, and internally linked | Essential content appears only after interaction or is blocked | Fix access and rendering before copy optimization |
| Semantics and accessibility | Logical headings, landmarks, descriptive links, and useful alt text | Visual hierarchy has no semantic equivalent | Repair document structure without changing the visual design unnecessarily |
| Structured data | JSON-LD describes visible, current facts and validates | Schema advertises hidden or invented content | Remove unsupported properties; use the narrowest relevant type |
| Decision support | Relevant pricing, fit, limitations, or comparisons are explicit | The page asks for conversion before answering objections | Add the missing decision information |
| Freshness | Review date is truthful and content-sensitive facts are current | Cosmetic date changes imply freshness | Update content first, then its visible and structured dates |

## Severity

- **Critical:** blocks access, misrepresents facts, hides material terms, or creates unsupported schema/claims.
- **High:** prevents a reader from understanding the offer, fit, evidence, or next step.
- **Medium:** weakens navigation, semantics, comparison, or trust but leaves the main decision possible.
- **Low:** polish that improves scanning or consistency.

## Scoring

Scores are directional, not a ranking prediction. Exclude dimensions that are not applicable instead of forcing every landing page to contain FAQs, comparison tables, pricing, or a personal byline. A high total never overrides a critical issue.
